# Code of conduct

This project is for building useful software together. Everyone taking part, in issues, pull requests, discussions and any other project space, agrees to the following.

## Expected behavior

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Give and accept feedback constructively. Review code and documentation, not the author.
- Be patient with newcomers and with people working in a second language.
- Respect privacy. Never share other people's personal information.

## Unacceptable behavior

- Harassment, insults, threats, discrimination or demeaning comments.
- Sexualized language or attention that is not wanted.
- Publishing private information without permission.
- Deliberately disrupting discussions, or pushing harmful or malicious code.

## Enforcement

Maintainers may edit or remove contributions, and may warn, temporarily restrict or permanently ban people who break these rules. To report a problem, use a private channel: GitHub's private vulnerability reporting form on the repository (choose it even for conduct reports and say so in the title), or ask in an issue for a private way to reach the maintainers without describing the problem publicly. Reports are treated with discretion.
